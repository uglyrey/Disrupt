# Просмотр дизайна на Mac

Чтобы посмотреть новый дизайн, не нужны сервер, база и Docker. Хватит python3, он уже есть в macOS.

```
cd <папка репозитория>
python3 scripts/design_preview.py
```

Скрипт напечатает адрес (по умолчанию `http://127.0.0.1:8765/`) и сам откроет браузер. Остановить его можно через Ctrl+C.

## Что внутри

- Страницы и файлы отдаются по тем же путям, что и в приложении: `/`, `/static/...`, `/privacy`, `/terms`, `/cookies`, `/data-deletion`.
- На `/health` и `/api/v1/*` отвечают тестовые данные. Это тестовый пользователь, десять заметок в категориях «Общее», «Учёба», «Стартап», «Работа», задачи, два напоминания, профиль. Записи, правки и категории сохраняются только в памяти до остановки скрипта.
- Неизвестные пути возвращают пустой ответ, страница не падает.
- Наружу скрипт не ходит и слушает только `127.0.0.1`. Метрика и внешние адреса не подключаются.

## Как войти

По умолчанию открывается главная страница без входа, с берёзой. Войти можно любым способом: «Войти по email» с любым адресом и любым кодом, «Войти через Telegram», логином и паролем. Настоящей проверки нет.

## Параметры

| Параметр | Что делает |
| --- | --- |
| `--port 9000` | другой порт, если 8765 занят (скрипт и сам ищет свободный рядом) |
| `--landing` | начать без входа, это поведение по умолчанию |
| `--signed-in` | сразу открыть приложение с тестовыми заметками |
| `--no-browser` | не открывать браузер |

## Берёза

Берёза строится скриптом `scripts/build_birch.py`. Для просмотра её перестраивать не нужно, готовые файлы лежат в `app/static`.

Описание дизайна: `docs/DESIGN.md`.
