# Повторный запуск админки

Запускайте прежний open-admin.cmd. Если проверенный SSH-туннель уже работает, скрипт открывает админку через него. Скрытое соединение может оставаться после закрытия старого окна.

Если порт занят другой программой или туннель не отвечает, выбирается свободный порт. Адрес открывается автоматически. Соединение привязано только к 127.0.0.1, проверка ключа сервера сохраняется.

Скрипт проверяет процесс OpenSSH, направление проброса и страницу админки. Он не закрывает чужие процессы и не завершает повторно используемый туннель. При выходе закрывается только соединение, созданное этим запуском.

Для диагностики можно запустить open-admin.ps1 с -CheckOnly. Параметр -TestConnection проверяет подключение без открытия браузера и закрывает только созданное тестовое соединение.

Серверы, пароли и аутентификаторы не меняются.
