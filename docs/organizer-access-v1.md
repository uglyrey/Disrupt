# Доступ организаторов

Откройте `https://app.berestaapp.ru/review`. Нужны отдельный логин наблюдателя,
пароль и текущий код из Google Authenticator или другого приложения TOTP.
SSH и VPN организатору не нужны.

Наблюдатель видит агрегаты и скачивает CSV или ZIP с обезличенными метриками.
Тексты заметок, аудио, контакты, обращения пользователей, журнал входов,
баланс ключа и управление аккаунтами недоступны.
Основной сценарий считается по `docs/contest-metrics-v2.md`. Зачёт прочих
компонентов требует согласования с организаторами.
Доступ сам по себе не подтверждает выполнение требований конкурса.

## Настройка владельцем

Нужны `NOTES_REVIEW_ENABLED=true`, HTTPS в `NOTES_PUBLIC_ORIGIN` и стабильный
`NOTES_ANALYTICS_PSEUDONYM_KEY_FILE`. По умолчанию портал выключен.
Приватные `/admin*` и `/static/admin.*` остаются закрытыми на Caddy и API.
Приложение отклоняет доступ к порталу по HTTP и через другой адрес.

Миграция `f8c42a19d063` добавляет роль и срок доступа. Существующие администраторы
получают роль `owner`. Пароли, зашифрованные ключи TOTP и сессии сохраняются.
Наблюдатель имеет роль `observer` и отдельную Secure cookie. Его сессия
не подходит для приватной админки. Изменять роль через браузер нельзя.

Создавайте отдельный аккаунт каждому эксперту.

```sh
python -m app.admin_cli create organizer-1 --role observer --expires 2026-12-01T00:00:00+03:00
python -m app.admin_cli confirm organizer-1 123456
python -m app.admin_cli disable organizer-1
```

Код в примере вымышленный. `confirm` выполняют с кодом из аутентификатора получателя.
Без этой команды аккаунт не работает. Без `--expires` срок составляет 14 дней.
Сессия живёт до 8 часов, без действий до 30 минут, всегда в пределах срока аккаунта.
`disable` сразу закрывает сессии. После пяти ошибок вход блокируется на 15 минут.

Для генерации пароля без вывода в терминал используйте `scripts/prepare_observer.py`
в контейнере API с приватным каталогом `/enroll`. Он сохраняет пароль и ключ
аутентификатора в файл с правами 600. Скачайте файл на ПК в каталог с закрытыми
правами, проверьте SHA256 и удалите временную серверную копию. Передавайте данные
конкретному получателю приватно. Не используйте аккаунты Марка или Андрея.

Для подтверждения с ПК владельца подходит `scripts/setup-admin.ps1 -Username organizer-1 -ConfirmOnly`.
После подтверждения организатор открывает `/review`, а не локальный `/admin`.
Передавать организатору SSH-ключ или доступ к VPS не нужно.

Выгрузки записываются в приватный журнал. Портал не принимает команды изменения
пользовательских данных. При откате схема не позволяет превратить наблюдателей
в владельцев. Не запускайте старый код без проверки роли, пока существуют
активные наблюдатели. Сначала отключите их; исходную схему возвращают только
после удаления таких аккаунтов и сохранения нужного журнала.
