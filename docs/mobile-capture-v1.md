# Телефон: запись первой, список по кнопке

Работает до 640px. На десктопе ничего не меняется.

## Виды

- После входа открыта «Новая запись», поле готово к вводу.
- Кнопка «Все заметки» над формой и пункт «Все заметки» в общем меню открывают список как отдельный вид. Для этого у `#workspace` стоит класс `library-open`.
- Кнопка `#mobile-back` над списком называется «Новая запись» и всегда приводит к форме записи. Если предыдущий шаг истории это сама форма, она делает Back. Если нет (до списка был раздел или заметка), она нажимает «Новая запись». В заметке она называется «Назад» и делает Back.
- Пункт «Новая запись» в общем меню и кнопка `#new-note` сами закрывают открытый список.
- При смене вида страница прокручивается наверх.
- Заметка из списка открывается на весь экран. Выход из неё возвращает туда, откуда пришли.
- Раздел (обзор, помощник, задачи) заменяет список. Кнопка «Все заметки» остаётся доступной.
- На кнопке показан счётчик заметок. Он виден только без фильтра, с плюсом, если есть следующие страницы.

## Кнопка «Назад»

Действующий маршрутизатор `navigation.js` использует `#notes` для списка и `#note=<id>` для заметки. Он сохраняет черновик и возвращает предыдущий экран при Back.

Если сохранение или черновик не дают уйти, запись истории возвращается обратно. В этом случае возможно одно «пустое» нажатие Back.

## Файлы

- `workspace.js`: кнопки телефона и счётчик заметок.
- `workspace.css`: правила видов.
- `brain.js`: пункт меню «Все заметки» использует действующий маршрутизатор.
- `tests/web_mobile_capture.cjs`: проверки, подключены из `web_structure.cjs`.

## Набор текста

Причина прыжков. При каждой букве поле заметки на секунду сжималось (`height:auto`), чтобы замерить высоту. Страница становилась короче, браузер сбрасывал прокрутку в 0, а старый код возвращал её обратно плавно, потому что в `polish.css` стоит `html{scroll-behavior:smooth}`. Это и давало прыжок наверх и «скатывание». Теперь `holdScroll` в `app.js` возвращает прокрутку сразу (`behavior:'instant'`). Фокус при входе в правку идёт с `preventScroll`, строка с кареткой ставится в середину.

`typewriter.js` держит строку с кареткой около середины видимой области (с учётом клавиатуры через `visualViewport`) в `#markdown` и `#thought`. Положение каретки измеряет скрытое зеркало поля. Работает только на ввод и клавиши курсора, раз в кадр, и только когда строка вышла из средней полосы. При `prefers-reduced-motion` без анимации. Свою прокрутку пользователя не трогает.
