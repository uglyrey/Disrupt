# Телефон: запись первой, список по кнопке

Работает до 640px. На десктопе ничего не меняется.

## Виды

- После входа открыта «Новая запись», поле готово к вводу.
- Кнопка «Все заметки» над формой и пункт «Все заметки» в общем меню открывают список как отдельный вид. Для этого у `#workspace` стоит класс `library-open`.
- Кнопка `#mobile-back` называется «Новая запись», если пришли с формы, и «Назад», если пришли из другого места.
- Заметка из списка открывается на весь экран. Выход из неё возвращает туда, откуда пришли.
- Раздел (обзор, помощник, задачи) заменяет список. Кнопка «Все заметки» остаётся доступной.
- На кнопке показан счётчик заметок. Он виден только без фильтра, с плюсом, если есть следующие страницы.

## Кнопка «Назад»

Каждый вход в список или заметку добавляет запись истории `#list` или `#note` (`history.state` с ключом `beresta`). Кнопка Android Back проходит их по одной. Лишние записи, которых уже нет, пропускаются. Разделы `brain.js` используют другие хеши (`overview`, `assistant`, `tasks`, `remind`) и с этим не пересекаются.

Если сохранение или черновик не дают уйти, запись истории возвращается обратно. В этом случае возможно одно «пустое» нажатие Back.

## Файлы

- `workspace.js`: блок телефона, `window.BerestaPhone`.
- `workspace.css`: правила видов.
- `brain.js`: пункт меню «Все заметки» вызывает `BerestaPhone.openList()`.
- `tests/web_mobile_capture.cjs`: проверки, подключены из `web_structure.cjs`.
