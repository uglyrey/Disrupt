# CSV для Excel

Выгрузки использовали запятую. На ПК владельца разделитель списка точка
с запятой, поэтому Excel помещал строку в одну ячейку.

Обычный CSV и все шесть CSV в архиве теперь используют точку с запятой,
UTF-8 с BOM и окончания строк CRLF. Заголовки остаются в первой строке,
служебной строки sep нет. Кавычки, переносы внутри ячеек и защита от формул
сохранены. Значения, пустые ячейки, десятичная точка и расчёт метрик не менялись.

Потребителям CSV нужно выбрать UTF-8-sig и разделитель ;. Новый формат
появляется при повторном скачивании, уже сохранённый файл сам не обновляется.

Ветка создана от установленного `5f28c1b`. Новые задачи, шапка, исправления
цитат и настройки таймаута коллеги сохранены. Миграций и зависимостей нет.
