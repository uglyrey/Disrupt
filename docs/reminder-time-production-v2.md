# Обновление времени напоминаний

Сборка совмещает установленную `9667f44` и PR #64 `6812932` в отдельной ветке. Main и PR коллеги не объединяются.

Сохранены почта, согласия, метрики, лимиты, картинки, импорт, навигация, дайджесты и текст главной страницы. В конфликте теста шифрования оставлены проверки картинок и ответов о времени.

На серверах уже применены корзина, часовые пояса и вход по коду. После `a17d6c9e24f0` добавляются `a3c5e7f9b1d2` и объединяющая миграция `b4d8f2a6c1e0`. Первая добавляет поля напоминаний и зашифрованную очередь уточнения времени. Вторая связывает истории без изменения данных.

`NOTES_STT_PROMPT` передаётся воркеру через Compose. По умолчанию в production пусто, чтобы сохранить проверенный формат запроса распознавания. Разбор времени словами работает независимо от подсказки. Поддержка непустого prompt настоящим шлюзом пока не проверена.

Перед установкой нужна согласованная age-копия, скачанная на ПК со сверкой SHA256. Миграции сначала проверяются на изолированно восстановленной базе. В этой среде не запускаются бот и обработчики реальных запросов.

Живые голосовые и ответы кнопками проверяет владелец после установки. Агент проверяет эти сценарии с mock и подменённым HTTP-транспортом.
