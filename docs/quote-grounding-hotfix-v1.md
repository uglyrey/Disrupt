# Приём ответа модели

11 октября две текстовые записи завершились `ungrounded_quote`.
Worker работал, шлюз возвращал ответ и usage. Следующее голосовое
обработалось успешно. Это отказ проверки цитат, а не недоступность сервера.

В адаптере структурирования добавлена обработка необязательных деталей.
Различия только в пробелах восстанавливаются в точный фрагмент исходника.
Пересказ и придуманные цитаты не принимаются. Неподтверждённый вывод или
item исключается; неподтверждённый срок становится null. Сама заметка
сохраняется с пояснением, если часть деталей исключена.

Серверная отметка передаётся приватным атрибутом, модель не может её задать
в JSON. Строгая проверка результата остаётся после исправления цитат.
Помощник, права доступа, бюджет и обработка ошибок шлюза не менялись.
Повторного HTTP-запроса нет. Исходники и аудио сохраняются как раньше.

Старые неуспешные задания не повторяются автоматически. Ответы этих
попыток не сохранялись, восстановить их без нового вызова нельзя.
Для проверки используются только синтетические данные и mock HTTP.
Миграции и новые зависимости не нужны, внешний JSON-контракт прежний.
