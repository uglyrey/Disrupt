# Приватная админка Андрея

Ваш ключ разрешён только для туннеля. SSH-оболочка, команды, SFTP, другие порты и передача агента запрещены. Основной сайт не открывает админку.

## Windows

1. Сохраните свой приватный SSH-ключ в `%USERPROFILE%\.ssh\beresta_admin`. Никому его не передавайте.
2. Один раз загрузите ключ через `ssh-add "$env:USERPROFILE\.ssh\beresta_admin"` в PowerShell. Парольную фразу вводите только на своём компьютере.
3. Откройте `open-admin.cmd`. Браузер откроется сам. Пока работаете, оставьте окно подключения открытым.
4. Войдите как `andrey`. Пароль и ключ Google Authenticator Марк передаст отдельно. Эти данные не находятся в архиве подключения.

Если файл ключа называется иначе, запустите `open-admin.ps1 -KeyPath "полный путь к вашему ключу"`.

## macOS и Linux

Скопируйте `beresta-admin.conf` и `beresta-admin-known-hosts` в `~/.ssh/`. В конфигурации указан ваш ключ `~/.ssh/beresta_admin`, при необходимости измените только этот путь. Загрузите его командой `ssh-add ~/.ssh/beresta_admin`.

Запустите `ssh -F ~/.ssh/beresta-admin.conf beresta-admin`. Откройте `http://127.0.0.1:18000/admin`. Завершайте соединение Ctrl+C.

Ключи серверов закреплены в файле known-hosts. При ошибке проверки ключа не отключайте её, обратитесь к Марку.

Вход с вашего компьютера и импорт TOTP ещё требуют вашей проверки. Пароль, TOTP и приватный SSH-ключ не присылайте в чат.
